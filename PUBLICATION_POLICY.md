# Publication boundary

Allowlist: README.md, PUBLICATION_POLICY.md, VALIDATION.md, requirements.txt, demo.py, test_demo.py, .gitignore, release_manifest.json.

Publish only the explicit files in this directory. Never stage the parent workspace or copy the private pilot wholesale. Review the exact diff and file list before each publication. New files require explicit selection; a successful text scan alone is not a data-rights assessment.

Excluded: original or transformed trajectories; topology/restart files; molecule-level or laboratory-derived aggregate outputs; trained models; private source hashes; machine paths, accounts, addresses and SSH configuration; Notion exports and meeting records; remote dispatchers; research-vendored code with unresolved redistribution scope. Public code preparation does not release the real-water training hold.

Future scientific results require a separate data/result publication decision. Public demonstration metrics must always be labeled synthetic. Do not claim q predicts water mobility from the artificial generator.

Repository: https://github.com/Youngchae2Lee/local-water-mobility-pilot . This repository has its own history, separate from the existing research repository.
